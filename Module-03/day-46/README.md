# TaskFlow Pro | Frontend Capstone Project

Production-grade task management web application built for the IBT College Canada CodeOps Full Stack Software Development Frontend Capstone [cite: 1].

## Local Setup Instructions
1. Clone the repository and install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.
